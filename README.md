# LearnSphere

LearnSphere is a responsive course-platform demo built with Next.js, React, TypeScript and Tailwind CSS. It began as a course UI clone and has been rebuilt into a connected end-to-end portfolio project.

## Working flows

- Browser-local learner profile
- Search and filter the catalogue
- Wishlist and course enrollment
- Embedded lessons and persisted module progress
- Editable profile and learning dashboard
- Certificate unlock and print flow at 100% completion
- Responsive navigation and accessible controls

## Local setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For production, run `npm run build` and `npm start`.

## Data note

This backend-free version stores demo profile and progress data in the current browser with `localStorage`. It does not collect passwords or payments. Production OAuth, database persistence and other optional features can be added next.
